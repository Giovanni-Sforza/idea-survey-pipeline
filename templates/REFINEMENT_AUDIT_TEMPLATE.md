## 5. Open issues at convergence

Issues that were raised at some round but were not fully addressed:

| Issue id | Round | Severity | Reason left open |
|---|---|---|---|
| R2-I05 | 2 | MAJOR | Lit-verifier returned `not_found`; reviewer-suggested fix requires a citation that doesn't exist in the searchable literature. Recommended: human-decide whether to weaken claim or accept caveat. |
| R3-I07 | 3 | MAJOR | Targeted tier-1 user_axiom; auto-revision refused per design. Human-decide. |
| R4-I02 | 4 | MINOR | OBSERVATION-class; deferred as nice-to-have. |

For each open issue, the user has three options:
1. **Accept the caveat** — add a note to the derivation's validity
   regime in `derivation-target.md` §5 and re-run.
2. **Weaken the claim** — edit `derivation-target.md` §1 (target
   observable phrasing) so the open issue is no longer a defect, and
   re-run.
3. **Invest more work** — invoke `/skill:research-debug` on the
   specific question, or run `/skill:analytic-derivation` on a sister
   sub-chain, or add a manual derivation step that resolves the gap.

## 7. Suggested next actions

(USER-FACING — these are commands you can run manually. The skill
does not invoke them.)

- If open issues remain that you want investigated independently:
  `/skill:research-debug "<one specific question>" — depth: L2`
- If a closely related observable was proposed by the `adversarial`
  reviewer and you want a separate derivation for it:
  `/skill:analytic-derivation "derive <new target> using anchors ..."`
- If the refined derivation is ready for inclusion in a formal
  document:
  `/skill:research-proposal "<your project topic>"`
  (the proposal skill will read `{REFINE_DIR}/current/derivation_steps.md`
  as ground truth for that section)
- If you want to re-run with more rounds or different reviewer mix:
  `/skill:derivation-refine-loop "{REFINE_DIR}/.." — max-rounds: 6 — reviewers: rigor,physics`

## 8. Resume / re-run hints

- A second invocation with the same `INPUT_DIR` argument
  automatically picks up at the highest existing round under
  `{REFINE_DIR}/round_*/` and continues. To force a clean re-run,
  delete the entire `{REFINE_DIR}/` directory.
- To re-run with FEWER reviewers (e.g. you trust the literature):
  `/skill:derivation-refine-loop "{INPUT_DIR}" — reviewers: rigor,physics`
- To allow more rounds: `— max-rounds: 6`.
- To tolerate one re-stated critical per round: `— convergence-delta: 1`.
- To raise the literature-search budget: `— lit-verify-budget: 5`.
